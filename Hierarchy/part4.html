4.1 — Key Takeaways

What Hierarchy Actually Does

A quick recap before the assessment. If any of this feels shaky, this is the moment to ask.

Definition: Visual hierarchy is the deliberate arrangement of elements to signal their relative importance and guide the viewer's eye in a specific sequence.
  • Hierarchy answers: What do I see first?
  • Then: What do I see next?
  • Then: What do I read last?
The Six Tools — Quick Recap
Tool 1
Size
Larger = more important.
Tool 2
Color
High saturation and contrast = more dominant.
Tool 3
Contrast
The highest-contrast element is seen first.
Tool 4
Spacing
More white space = more important.
Tool 5
Typography
Size, weight, style, and color create text levels.
Tool 6
Placement
Higher, centered, and left-placed elements are seen first.
Remember: Hierarchy and balance work together — a design can be balanced and have a clear hierarchy.
Watch for: Weak hierarchy — where everything looks equally important — is the most common beginner design mistake.
Payoff: Strong hierarchy makes designs faster to read, easier to understand, and more professional.
4.2 — Assessment Questions

Short Answer — Individual Work

10 minutes, working alone. Answer each question in your own words.

  1. 1Define visual hierarchy in your own words. Why is it considered a fundamental principle of graphic design?
  2. 2A designer creates a poster where the headline, subheading, and body text are all the same size and color. What hierarchy problem does this create? Name two tools they could use to fix it.
  3. 3Explain how spacing (white space) creates hierarchy. Give one real-world example.
  4. 4What is the difference between the F-pattern and the Z-pattern reading models? When would you use each?
  5. 5A design looks great in full color but loses all hierarchy when viewed in greyscale. What does this tell you about the design's hierarchy? How would you fix it?

4.3 — Comparison Table

Strong vs. Weak Hierarchy

Use this as a checklist when critiquing your own work.

FeatureStrong HierarchyWeak Hierarchy
SizeClear size differences between levelsAll elements are similar in size
ColorAccent color used for the most important elementMultiple vivid colors compete for attention
ContrastHigh contrast for primary elementsLow or equal contrast throughout
SpacingGenerous space around key elementsCrowded, no breathing room
Typography3–4 distinct typographic levelsAll text looks the same
PlacementMost important content is top/centerImportant content is buried or off-center
Viewer ExperienceEye moves naturally through the designViewer is confused about where to start
4.4 — Assignment

Create a Hierarchy Comparison

Using any design tool (Canva, Adobe Express, Figma, MS Word, or hand-drawn):

Version A — Weak Hierarchy
Everything Equal
Create a simple event poster or product flyer where all elements have the same size, color, and weight. Everything looks equally important.
Version B — Strong Hierarchy
Three Clear Levels
Redesign the same poster applying at least four of the six tools to create a clear 3-level hierarchy (headline → subheading → body/details).
Written Reflection (5–7 sentences): Describe which tools you used in Version B and explain how each one contributes to the hierarchy.
Submission: Next class meeting.
Evaluation Criteria
✓Version A clearly demonstrates the absence of hierarchy
✓Version B has at least 3 visually distinct levels
✓At least 4 of the 6 tools are applied and identifiable
✓Written reflection accurately describes the tools used
