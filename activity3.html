🖼 The Blurry Tarpaulin Logo

❌ Enlarged raster logo
✅ Vector logo (crisp at any size)
"This logo looks fuzzy and jagged when we make it big. What is the mistake, and what should we use instead?"

❌ Mistake

Used a raster / JPG / PNG file — made of fixed pixels that break apart when enlarged.

✅ Fix

Use a vector / SVG / EPS file — it scales to any size without losing quality.

💡 CG Link: This comes straight from learning how computers store and render shapes — raster vs. vector graphics!

CMYK Mismatch
"It looked perfect on my laptop, but printed all dull and gray! Why did this happen?"

❌ Mistake

Saved the file in RGB color mode — designed for screens that emit light, not for print.

✅ Fix

Switch to CMYK mode before sending to the printer to get accurate printed colors.

💡 CG Link: Computer graphics explains how screens (additive RGB) and printers (subtractive CMYK) produce color differently!

👁 The Invisible Warning Text

❌ Bad
⚠ LOW DISK SPACE
Light gray on white
✅ Good
⚠ LOW DISK SPACE
Dark text on white
"My classmates say they can barely read this text. What rule did I break?"

❌ Mistake

Too low color contrast between text and background — light gray on white is nearly invisible.

✅ Fix

Use a dark text color (dark gray or black) to meet accessibility contrast standards (WCAG AA).

💡 CG Link: We learn contrast ratios and visual processing in computer graphics — it's not just art, it's science!
