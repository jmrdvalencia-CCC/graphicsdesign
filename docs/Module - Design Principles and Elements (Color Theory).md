## PART 1: WHAT IS COLOR THEORY? (25 minutes)

### 1.1 Definition

**Color theory** is the body of practical guidance for mixing colors and the visual effects of specific color combinations. In graphic design, it is the systematic framework that explains *why* certain color choices work, *how* colors interact with each other, and *what* emotional and communicative effects they produce.

According to *Mrantinkovic et al. (2020)*, color is one of the most powerful elements in a designer's toolkit — it communicates before the viewer reads a single word, and it shapes how the entire design is perceived.

> **Key Concept:** Color is never neutral. Every color choice communicates something — mood, priority, brand identity, cultural meaning, and emotional tone. A designer who understands color theory makes intentional choices; one who doesn't makes accidental ones.

Color theory in graphic design rests on three foundational pillars:

| Pillar | What It Covers |
|---|---|
| 🎨 **The Color Wheel** | How colors relate to each other and how to build harmonious combinations |
| 🧠 **Color Psychology** | The emotional and behavioral responses colors trigger in viewers |
| 🖨️ **Color Systems** | How color is produced and reproduced across different media (screen vs. print) |

---

### 1.2 A Brief History of Color Theory

Understanding where color theory comes from helps explain why it works.

| Era | Contributor | Contribution |
|---|---|---|
| 1666 | **Isaac Newton** | Discovered that white light splits into a spectrum through a prism; created the first circular color diagram |
| 1810 | **Johann Wolfgang von Goethe** | Published *Theory of Colors* — the first systematic study of the psychological effects of color |
| 1840 | **Michel Eugène Chevreul** | Identified the law of simultaneous contrast — colors look different depending on what surrounds them |
| 1920s | **Bauhaus School** | Integrated color theory into design education; Johannes Itten and Josef Albers developed foundational color exercises still used today |
| 1963 | **Josef Albers** | Published *Interaction of Color* — demonstrated that color perception is relative, not absolute |

> **Key Insight:** Color theory is not a set of rigid rules — it is a set of principles based on how human vision and perception actually work *(Mrantinkovic et al., 2020)*. Understanding the principles allows designers to break them intentionally.

---

### 1.3 The Color Wheel

The **color wheel** is the primary organizational tool of color theory. It arranges colors in a circular format to show their relationships.

#### Primary Colors

The three colors that cannot be mixed from any other colors. All other colors are derived from them.

```
        🔴 RED
       /       \
      /         \
🔵 BLUE ——— 🟡 YELLOW
```

| Color Model | Primary Colors | Used In |
|---|---|---|
| **RYB** (Traditional) | Red, Yellow, Blue | Fine art, painting, traditional design education |
| **RGB** (Additive) | Red, Green, Blue | Screens, monitors, digital design, web |
| **CMYK** (Subtractive) | Cyan, Magenta, Yellow, Key (Black) | Print, offset printing, physical media |

> **Important:** Graphic designers must understand both RGB (for screen) and CMYK (for print). A color that looks vivid on screen may appear dull when printed if not properly converted.

#### Secondary Colors

Mixed from two primary colors in equal parts.

| Mix | Result |
|---|---|
| Red + Yellow | **Orange** |
| Yellow + Blue | **Green** |
| Blue + Red | **Violet / Purple** |

#### Tertiary Colors

Mixed from one primary and one adjacent secondary color. Named by combining both parent color names (primary first):

- Red-Orange · Yellow-Orange · Yellow-Green
- Blue-Green · Blue-Violet · Red-Violet

#### The Full Color Wheel

```
            YELLOW
          /        \
   Yellow-Green    Yellow-Orange
        /                \
     GREEN              ORANGE
        \                /
   Blue-Green       Red-Orange
          \        /
            BLUE — — — RED
          /        \
   Blue-Violet    Red-Violet
          \        /
           VIOLET
```

### 1.4 Properties of Color

Every color can be described using four core properties. Understanding these allows precise, intentional color control.

#### Hue

**Hue** is the pure color itself — what we mean when we say "red," "blue," or "green." It is the color's position on the color wheel, with no white, black, or grey added.

#### Value (Lightness / Darkness)

**Value** describes how light or dark a color is.

- Adding **white** to a hue creates a **tint** (lighter version)
- Adding **black** to a hue creates a **shade** (darker version)
- Adding **grey** to a hue creates a **tone** (muted version)

```
TINT ←————————————————————→ SHADE
White + Hue          Hue          Hue + Black
(Lightest)          (Pure)        (Darkest)
```

> **Design Application:** Value contrast is the most important factor in readability. Even if you remove all color (greyscale), a design with strong value contrast will remain legible and hierarchically clear.

#### Saturation (Chroma / Intensity)

**Saturation** describes how vivid or muted a color is — its purity or intensity.

- **High saturation** = vivid, intense, pure color (e.g., a fire-engine red)
- **Low saturation** = muted, grey-ish, desaturated color (e.g., a dusty rose)

```
HIGH SATURATION ←————————————→ LOW SATURATION
Vivid · Intense · Pure       Muted · Greyed · Soft
```

> **Design Application:** Highly saturated colors attract attention and feel energetic or urgent. Desaturated colors feel calm, sophisticated, or secondary. Hierarchy is often built by giving the most important element the highest saturation.

#### Color Temperature

**Color temperature** describes the perceived warmth or coolness of a color.

| Temperature | Colors | Psychological Effect |
|---|---|---|
| **Warm** | Red, Orange, Yellow, Yellow-Green | Energetic, urgent, passionate, advancing (feel closer) |
| **Cool** | Blue, Blue-Green, Violet, Blue-Violet | Calm, trustworthy, receding (feel farther away) |
| **Neutral** | Pure Green, Pure Red-Violet, Black, White, Grey | Balanced, versatile, neither advancing nor receding |

> **Design Application:** Warm colors naturally advance in a composition — they feel closer to the viewer. Cool colors recede. This is why a warm-colored call-to-action button on a cool-colored background immediately draws the eye.

## PART 2: COLOR HARMONIES AND SCHEMES (35 minutes)

A **color harmony** is a combination of colors that is visually pleasing because of the structured relationship between the colors on the color wheel. Harmonies give designers a systematic way to build color palettes that feel intentional and cohesive *(Mrantinkovic et al., 2020)*.

---

### 2.1 Monochromatic

**Definition:** Uses a single hue with variations in value (tints, tones, and shades).

```
BASE HUE:  ████  (e.g., Blue)
Tint:      ░░░░  (Blue + White)
Tone:      ▒▒▒▒  (Blue + Grey)
Shade:     ████  (Blue + Black)
```

| Strengths | Weaknesses |
|---|---|
| Highly cohesive and unified | Can feel monotonous or flat |
| Easy to maintain brand consistency | Limited contrast between elements |
| Feels sophisticated and elegant | May lack visual energy |

**Best Used For:** Minimalist designs, luxury branding, backgrounds, single-product photography.

**Real-World Example:** Many luxury fashion brands (e.g., Chanel) use monochromatic black-and-white palettes to communicate elegance and timelessness.

---

### 2.2 Analogous

**Definition:** Uses 3–5 colors that sit adjacent to each other on the color wheel.

```
Color Wheel Position:
[ Yellow-Green ] — [ Green ] — [ Blue-Green ] — [ Blue ]
        ↑ Analogous colors — neighboring, harmonious
```

| Strengths | Weaknesses |
|---|---|
| Naturally harmonious and pleasing | Low contrast between colors |
| Found frequently in nature | Can be hard to establish hierarchy |
| Creates a strong mood or atmosphere | May feel too similar without value variation |

**Best Used For:** Nature-themed designs, mood-driven illustrations, backgrounds, seasonal campaigns.

**Real-World Example:** A sunset poster using yellow, orange, and red-orange — all adjacent on the wheel — creates a warm, cohesive atmosphere.

> 💬 **Discussion:** Look at a landscape photograph. Can you identify an analogous color palette in nature? How does it make you feel compared to a design with contrasting colors?

---

### 2.3 Complementary

**Definition:** Uses two colors directly opposite each other on the color wheel.

```
Color Wheel:
RED ←————————————→ GREEN   (opposite)
BLUE ←———————————→ ORANGE  (opposite)
YELLOW ←—————————→ VIOLET  (opposite)
```

| Strengths | Weaknesses |
|---|---|
| Maximum contrast and visual energy | Can feel harsh or vibrating if used at full saturation |
| Creates strong focal points | Difficult to balance — one color must dominate |
| Highly attention-grabbing | Can feel aggressive or overwhelming |

**Best Used For:** Call-to-action buttons, sports branding, sale/promotional materials, warning signs.

**Real-World Example:** The Los Angeles Lakers (purple and gold/yellow) — a complementary pair that creates high visual energy and instant recognizability.

> ⚠️ **Common Mistake:** Using both complementary colors at equal saturation and equal proportion. One color must be dominant (60–70%) and the other used as an accent (30–40%) to avoid visual chaos.

---

### 2.4 Split-Complementary

**Definition:** Uses one base color and the two colors on either side of its complement (not the complement itself).

```
Base Color:  BLUE
Complement:  ORANGE
Split:       YELLOW-ORANGE  +  RED-ORANGE
                    ↑ Use these two instead of orange
```

| Strengths | Weaknesses |
|---|---|
| High contrast without the harshness of complementary | More complex to balance than complementary |
| More variety than complementary | Requires careful proportion management |
| Easier to work with for beginners | Can feel busy if all three are used equally |

**Best Used For:** Designs that need energy and contrast but with more visual sophistication than a straight complementary scheme.

---

### 2.5 Triadic

**Definition:** Uses three colors equally spaced around the color wheel (120° apart).

```
Color Wheel (equally spaced):
🔴 RED — 🟡 YELLOW — 🔵 BLUE   (Primary triad)
🟠 ORANGE — 🟢 GREEN — 🟣 VIOLET  (Secondary triad)
```

| Strengths | Weaknesses |
|---|---|
| Vibrant and visually rich | Difficult to balance — all three compete |
| Strong visual variety | Can feel chaotic without careful proportion |
| Works well for playful, energetic designs | Not suitable for minimalist or luxury aesthetics |

**Best Used For:** Children's media, entertainment, sports, playful branding, infographics.

**Real-World Example:** Google's logo uses a triadic-adjacent palette (red, yellow, blue, green) to communicate playfulness, accessibility, and diversity.

> 💬 **Discussion:** Why do you think children's toy brands (like LEGO or Fisher-Price) almost always use triadic or near-triadic color schemes? What does this communicate to the audience?

---

### 2.6 Tetradic (Double Complementary)

**Definition:** Uses four colors — two complementary pairs. Forms a rectangle on the color wheel.

```
Pair 1:  RED ←————→ GREEN
Pair 2:  BLUE ←———→ ORANGE
                ↑ Rectangle on the color wheel
```

| Strengths | Weaknesses |
|---|---|
| Rich, complex palette with many options | Hardest scheme to balance |
| Allows for warm/cool contrast within one palette | Risk of visual overload |
| Versatile for complex, multi-section designs | Requires one dominant color and careful restraint |

**Best Used For:** Complex editorial layouts, infographics, multi-category branding systems.

> **Rule:** In a tetradic scheme, choose one dominant color (50%), one secondary (30%), and use the remaining two as accents (10% each). Never use all four at equal weight.

---

### 2.7 The 60-30-10 Rule

Regardless of which color harmony you choose, the **60-30-10 rule** is the most reliable formula for applying a color palette in a design.

```
60% — Dominant Color    (backgrounds, large areas)
30% — Secondary Color   (headers, sidebars, large elements)
10% — Accent Color      (buttons, highlights, key details)
```

> **Why It Works:** This ratio mirrors proportions found in nature and interior design. It creates visual balance while still allowing one color to clearly dominate — which reinforces hierarchy *(Mrantinkovic et al., 2020)*.

**Example Application:**

| Area | Color | Proportion |
|---|---|---|
| Page background | Light grey (neutral) | 60% |
| Section headers and cards | Deep navy blue | 30% |
| Call-to-action buttons, links | Vivid orange | 10% |

## PART 3: COLOR PSYCHOLOGY AND CULTURAL MEANING (20 minutes)

### 3.1 Color Psychology

Color psychology is the study of how colors affect human behavior, emotion, and perception. In graphic design, understanding color psychology allows designers to align the emotional tone of a design with its intended message *(Mrantinkovic et al., 2020)*.

> **Important:** Color psychology describes *tendencies*, not absolutes. Individual responses to color vary based on personal experience, context, and culture. However, broad patterns are consistent enough to be reliable design tools.

#### Color Meanings and Associations

| Color | Positive Associations | Negative Associations | Common Industries |
|---|---|---|---|
| 🔴 **Red** | Energy, passion, urgency, excitement, love | Danger, aggression, warning, anger | Food, retail (sales), entertainment, emergency |
| 🟠 **Orange** | Warmth, enthusiasm, creativity, friendliness, affordability | Cheapness, over-stimulation | Food, retail, children's products, fitness |
| 🟡 **Yellow** | Optimism, happiness, clarity, warmth, attention | Caution, anxiety, cowardice | Food, children's media, warnings, taxis |
| 🟢 **Green** | Nature, health, growth, freshness, wealth, safety | Envy, inexperience | Health, food, finance, environment, pharmacy |
| 🔵 **Blue** | Trust, reliability, calm, professionalism, intelligence | Coldness, sadness, distance | Technology, finance, healthcare, corporate |
| 🟣 **Violet / Purple** | Luxury, creativity, wisdom, spirituality, mystery | Excess, artificiality | Beauty, luxury goods, spirituality, education |
| 🩷 **Pink** | Romance, softness, playfulness, femininity, care | Weakness, immaturity | Beauty, fashion, children's products, healthcare |
| 🟤 **Brown** | Earthiness, reliability, warmth, naturalness, stability | Dullness, heaviness | Food, coffee, outdoor/nature brands, furniture |
| ⚫ **Black** | Sophistication, luxury, power, elegance, authority | Death, mourning, evil, emptiness | Luxury, fashion, technology, formal contexts |
| ⚪ **White** | Cleanliness, simplicity, purity, space, minimalism | Coldness, emptiness, sterility | Healthcare, technology, minimalist brands |
| 🩶 **Grey** | Neutrality, professionalism, balance, timelessness | Boredom, indecision, lack of energy | Corporate, technology, automotive |

### 3.2 Color in Branding — Real-World Applications

Color is one of the most powerful tools in brand identity. Research suggests that color increases brand recognition by up to **80%** and influences up to **85%** of purchasing decisions.

| Brand | Primary Color | Why That Color |
|---|---|---|
| **McDonald's** | Red + Yellow | Red triggers hunger and urgency; yellow communicates happiness and affordability |
| **Facebook / Meta** | Blue | Communicates trust, reliability, and calm — critical for a social platform |
| **Spotify** | Green | Communicates freshness, energy, and growth; stands out in the tech space |
| **Tiffany & Co.** | Robin's Egg Blue | Proprietary color communicating luxury, exclusivity, and elegance |
| **Coca-Cola** | Red | Energy, excitement, passion — the color is so associated with the brand it is called "Coca-Cola Red" |
| **IKEA** | Blue + Yellow | Swedish national colors; blue = trust, yellow = affordability and optimism |

> 💬 **Discussion:** Think of a brand whose color you immediately recognize. If that brand changed its primary color tomorrow, how would your perception of it change? What does this tell you about the power of color in identity?

### 3.3 Cultural Considerations in Color

Color meanings are **not universal**. The same color can carry completely different — even opposite — meanings across cultures. Designers working for global or multicultural audiences must research cultural color associations carefully.

| Color | Western Meaning | Eastern / Other Meaning |
|---|---|---|
| **White** | Purity, weddings, cleanliness | Mourning, death, funerals (China, Japan, Korea) |
| **Red** | Danger, warning, passion | Luck, prosperity, celebration (China); purity (India) |
| **Green** | Nature, health, go/safe | Infidelity (China); death (some Latin American cultures) |
| **Yellow** | Happiness, caution | Sacred, imperial (China); mourning (Egypt, some Middle Eastern cultures) |
| **Purple** | Luxury, royalty | Mourning (Brazil, Thailand); expensive/sacred (Japan) |
| **Blue** | Trust, calm, corporate | Immortality (Iran); mourning (Korea); protection (Middle East |

> ⚠️ **Design Warning:** A color palette that works perfectly for a North American audience may send unintended messages to an Asian or Latin American audience. Always research cultural color associations when designing for international markets.

## PART 4: COLOR SYSTEMS AND PRACTICAL APPLICATION (15 minutes)

### 4.1 Color Models: RGB vs. CMYK

Understanding the difference between color models is essential for professional design work. Using the wrong model results in colors that look correct on screen but print incorrectly — or vice versa.

#### RGB (Red, Green, Blue) — Additive Color

- Used for **screens**: monitors, phones, tablets, TVs, projectors
- Colors are created by **adding light** — combining all three at full intensity produces white
- Color values range from **0–255** per channel (e.g., pure red = R:255, G:0, B:0)
- Capable of producing a **wider gamut** (range) of colors than CMYK

```
RGB Mixing (Additive):
Red + Green = Yellow
Green + Blue = Cyan
Blue + Red = Magenta
Red + Green + Blue = White
No light = Black
```

#### CMYK (Cyan, Magenta, Yellow, Key/Black) — Subtractive Color

- Used for **print**: offset printing, digital printing, packaging
- Colors are created by **subtracting light** — ink absorbs certain wavelengths
- Color values expressed as **percentages** (e.g., pure cyan = C:100, M:0, Y:0, K:0)
- **Smaller gamut** than RGB — some vivid RGB colors cannot be reproduced in CMYK

```
CMYK Mixing (Subtractive):
Cyan + Magenta = Blue
Magenta + Yellow = Red
Yellow + Cyan = Green
Cyan + Magenta + Yellow = Dark Brown (not black — this is why K/Black ink is added)
```

> ⚠️ **Critical Rule:** Always design in **RGB for screen** and convert to **CMYK for print**. Never design a print project in RGB and expect the colors to match — they will not. Always request a physical proof before final printing.

---

### 4.2 Hex Codes and Color Notation

In digital design, colors are specified using standardized notation systems.

| System | Format | Example | Used In |
|---|---|---|---|
| **Hex Code** | #RRGGBB (hexadecimal) | `#7c3aed` (purple) | Web, CSS, digital design tools |
| **RGB** | rgb(R, G, B) | `rgb(124, 58, 237)` | Web, CSS, screen design |
| **RGBA** | rgba(R, G, B, A) | `rgba(124, 58, 237, 0.5)` | Web/CSS with transparency |
| **HSL** | hsl(H°, S%, L%) | `hsl(262, 83%, 58%)` | Web/CSS, intuitive for designers |
| **CMYK** | C%, M%, Y%, K% | `C:48, M:76, Y:0, K:7` | Print, InDesign, Illustrator |
| **Pantone (PMS)** | PMS [number] | `PMS 2665 C` | Brand standards, physical printing |

> **Professional Practice:** Brand guidelines always specify colors in multiple formats — Hex for web, RGB for screen, CMYK for print, and Pantone for physical materials. This ensures color consistency across all media.

---

### 4.3 Practical Color Selection Process

When choosing a color palette for a design project, follow this structured process:

**Step 1 — Define the Intent**
- What emotion should the design evoke?
- Who is the audience? What are their cultural backgrounds?
- What is the brand personality? (e.g., playful, professional, luxurious, urgent)

**Step 2 — Choose a Base Color (Hue)**
- Select a hue that aligns with the psychological intent
- Consider the industry conventions (but don't be limited by them)

**Step 3 — Choose a Harmony**
- Select a color harmony based on the design's complexity and energy level
- Simple, elegant designs → monochromatic or analogous
- High-energy, attention-grabbing designs → complementary or triadic

**Step 4 — Adjust Value and Saturation**
- Create tints, tones, and shades of your chosen colors
- Ensure sufficient value contrast for readability and hierarchy

**Step 5 — Apply the 60-30-10 Rule**
- Assign proportions: dominant (60%), secondary (30%), accent (10%)
- Test in greyscale — hierarchy should still be clear without color

**Step 6 — Test Accessibility**
- Check contrast ratios for text readability (WCAG standard: minimum 4.5:1 for body text)
- Test for color blindness compatibility (approximately 8% of males have some form of color vision deficiency)

## PART 5: GROUP ACTIVITY — COLOR CRITIQUE & REDESIGN (20 minutes)

### Activity Overview

Students are divided into **3 groups**. Each group receives a design sample and completes a structured color analysis and critique.

**Time:** 12 minutes group work + 8 minutes group presentations (2–3 min each)

---

### Group 1 — Brand Color Analysis

**Sample:** Choose any well-known brand logo (e.g., a fast food chain, a tech company, a sports brand).

**Tasks:**
1. Identify the color harmony being used (monochromatic, complementary, analogous, etc.).
2. Describe the psychological associations of each color in the palette.
3. Explain how the color choices align with (or contradict) the brand's intended message.
4. Propose one alternative color palette that would change the brand's perceived personality.
5. Present: *"This brand uses ___ harmony. The colors communicate ___ because ___. If they changed to ___, the brand would feel ___."*

**Guide Questions:**
- Would you trust this brand more or less if its colors were different?
- Is the color palette consistent with the industry it operates in?
- Does the color palette stand out from competitors, or does it blend in?

---

### Group 2 — Poster Color Critique

**Sample:** A promotional poster (event, product, or public service announcement).

**Tasks:**
1. Identify the dominant, secondary, and accent colors. Estimate the 60-30-10 proportions.
2. Evaluate whether the color hierarchy supports the visual hierarchy (does the most important element have the most attention-grabbing color?).
3. Identify any color psychology mismatches (e.g., a children's event poster using dark, muted colors).
4. Redesign the color palette using a different harmony while keeping the same layout.
5. Present: *"The original palette uses ___ and creates a ___ feeling. Our redesign uses ___ because ___."*

**Guide Questions:**
- Does the color palette match the target audience?
- Is there a clear focal point created by color?
- Would the design work in greyscale? Why or why not?

---

### Group 3 — Website Color Accessibility Audit

**Sample:** A website screenshot (any website the group chooses or is assigned).

**Tasks:**
1. Identify the color palette — list the main colors used.
2. Evaluate the text-to-background contrast. Is it readable? (High contrast = good; low contrast = accessibility problem)
3. Identify which color harmony is being used.
4. Find one color decision that works well and one that could be improved.
5. Present: *"The website uses ___ harmony. The contrast is ___ because ___. We would improve ___ by ___."*

**Guide Questions:**
- Can you read all the text easily? If not, which text has a contrast problem?
- Does the color palette feel consistent throughout the site?
- Does the accent color clearly identify the most important interactive elements (buttons, links)?

---

### Presentation Format (2–3 min per group)

Each group shares:
1. The design they analyzed and the color palette they identified
2. The harmony type and psychological associations
3. One strength and one weakness in the color use
4. Their proposed improvement or redesign

## PART 6: SUMMARY & ASSESSMENT (5 minutes)

### 6.1 Key Takeaways

1. **Color theory** is the systematic framework for understanding how colors relate, interact, and communicate — it is the foundation of intentional color use in design.
2. Every color has four core properties: **hue** (the color itself), **value** (light/dark), **saturation** (vivid/muted), and **temperature** (warm/cool).
3. The **color wheel** organizes colors into relationships — primary, secondary, and tertiary — and is the basis for all color harmonies.
4. The six main **color harmonies** are: monochromatic, analogous, complementary, split-complementary, triadic, and tetradic. Each creates a different visual energy and mood.
5. The **60-30-10 rule** is the most reliable formula for applying a color palette: 60% dominant, 30% secondary, 10% accent.
6. **Color psychology** describes the emotional and behavioral responses colors trigger — these tendencies are consistent enough to be reliable design tools, but cultural context always matters.
7. **RGB** is for screens; **CMYK** is for print. Using the wrong model causes color inconsistency between digital and physical outputs.
8. Strong color use **reinforces hierarchy** — the most important element should have the most visually dominant color treatment.

---

### 6.2 Assessment Questions

**Short Answer (Individual — 10 minutes):**

1. Define color theory in your own words. Why is it considered a fundamental principle of graphic design?
2. Explain the difference between **hue**, **value**, and **saturation**. Give one design example of how each property can be used to create visual hierarchy.
3. A designer is creating a poster for a children's birthday party. They choose a monochromatic dark navy blue palette. What color theory problem does this create? What harmony would you recommend instead, and why?
4. Explain the **60-30-10 rule**. Why does this proportion work better than using three colors in equal amounts?
5. A design looks great on screen but the colors appear dull and different when printed. What is the likely cause of this problem? How would you prevent it in future projects?

### 6.3 Comparison Table: Effective vs. Ineffective Color Use

| Feature | Effective Color Use | Ineffective Color Use |
|---|---|---|
| **Harmony** | Colors are chosen from a deliberate harmony | Colors are chosen randomly with no relationship |
| **Hierarchy** | Most important element has the most dominant color | All elements compete with equal color weight |
| **Proportion** | 60-30-10 rule applied — one color clearly dominates | All colors used in equal amounts |
| **Psychology** | Color mood matches the design's intent and audience | Color mood contradicts the message (e.g., red for a spa) |
| **Contrast** | Sufficient value contrast for readability | Low contrast makes text hard to read |
| **Consistency** | Color palette is consistent throughout the design | Colors change randomly between sections |
| **Cultural Fit** | Colors are appropriate for the target culture | Colors carry unintended cultural meanings |
| **Media Accuracy** | Correct color model used (RGB for screen, CMYK for print) | Wrong color model causes color shifts between media |

### 6.4 Assignment

**Create a Color Palette Presentation:**

Using any design tool (Canva, Adobe Express, Figma, Adobe Color, or hand-drawn swatches):

1. **Choose a Design Brief:** Select one of the following — a café brand, a fitness app, a children's book cover, or a luxury watch advertisement.
2. **Build Two Color Palettes:**
   - **Palette A:** Choose a color harmony that *does not* match the brief's intended mood. Explain why it fails.
   - **Palette B:** Choose a color harmony that *does* match the brief's intended mood. Apply the 60-30-10 rule.
3. **Apply Palette B** to a simple mock-up: a business card, a social media post, or a poster layout.
4. **Written Reflection (5–7 sentences):** Describe the harmony you chose for Palette B, the psychological associations of each color, and how the 60-30-10 proportion was applied.

**Submission:** Next class meeting

**Evaluation Criteria:**
- Palette A clearly demonstrates a color/mood mismatch with written explanation
- Palette B uses a named, identifiable color harmony
- The 60-30-10 rule is visibly applied in the mock-up
- Written reflection accurately identifies the harmony, psychology, and proportion
- Mock-up demonstrates understanding of color hierarchy (most important element has most dominant color)
