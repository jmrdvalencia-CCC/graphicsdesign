## WHAT IS ADOBE PHOTOSHOP?

**Adobe Photoshop** is a powerful, industry-standard raster graphics editor developed by Adobe Inc. It is used for creating, editing, and enhancing digital images, illustrations, and designs. Photoshop is used by photographers, graphic designers, UI/UX designers, and digital artists for tasks ranging from basic photo retouching to complex compositing, digital painting, and print production.

**Current Version:** Adobe Photoshop (2025) — part of Adobe Creative Cloud.

**Common Uses:**
- Photo retouching and restoration
- Digital painting and illustration
- Compositing (combining multiple images)
- UI mockups and web graphics
- Print design (posters, brochures, packaging)
- Social media content creation

## PART 1: PARTS OF THE PHOTOSHOP INTERFACE (30 minutes)

The Photoshop workspace is made up of five main areas. Understanding each one is essential before using any tool.

---

### 1. Menu Bar

Located at the very **top** of the application window, the Menu Bar provides access to all major commands and settings organized into dropdown menus:

| Menu | Key Functions |
|---|---|
| **File** | New, Open, Save, Export, Place |
| **Edit** | Undo, Transform, Fill, Preferences |
| **Image** | Adjustments, Canvas Size, Image Size, Mode |
| **Layer** | New Layer, Merge, Flatten, Layer Styles |
| **Select** | All, Deselect, Inverse, Modify, Color Range |
| **Filter** | Blur, Sharpen, Distort, Noise, Smart Filters |
| **View** | Zoom, Rulers, Guides, Proof Colors |
| **Window** | Show/hide panels (Layers, History, Properties, etc.) |
| **Help** | Tutorials, About Photoshop |

> **Tip:** Most Menu Bar commands have keyboard shortcuts listed beside them. Learning these shortcuts dramatically speeds up your workflow.

---

### 2. Options Bar

Located **below the Menu Bar**, the Options Bar is context-sensitive — its content changes depending on which tool is currently selected. It allows you to customize the behavior of the active tool.

**Examples:**
- With the **Brush Tool** selected: shows brush size, hardness, opacity, and flow.
- With the **Move Tool** selected: shows alignment options and auto-select settings.
- With the **Crop Tool** selected: shows aspect ratio, resolution, and straighten options.

> **Key Point:** Always check the Options Bar after selecting a tool. Many beginners miss important settings because they overlook this bar.

---

### 3. Toolbar (Tools Panel)

The **Toolbar** is the vertical panel on the **left side** of the workspace. It contains icons for all of Photoshop's tools, organized into groups:

- Selection tools (Move, Marquee, Lasso, Magic Wand)
- Crop and Slice tools
- Measurement tools
- Retouching and Painting tools
- Drawing and Type tools
- Navigation tools (Zoom, Hand)

**If the Toolbar is missing:** Go to **Window > Tools** to restore it.

**To customize the Toolbar:** Go to **Edit > Toolbar** to add, remove, or reorganize tools into groups that suit your workflow.

> **Note:** Some tools are hidden under others. A small **triangle arrow** in the bottom-right corner of a tool icon indicates a flyout menu with additional tools. Right-click the icon to reveal them.

---

### 4. Canvas / Document Window (Working Space)

The **Canvas** is the central area of the workspace — the digital surface where you create and edit your image. It represents the actual document you are working on.

- **Canvas size** = the dimensions of your final output (e.g., 1080×1080 px for Instagram).
- **Artboard** = an extended canvas feature that allows multiple canvases within one document (useful for UI design and multi-page layouts).
- The grey area surrounding the canvas is the **pasteboard** — you can place elements here temporarily, but they will not appear in the final export.

**To create a new canvas:** File > New — then set width, height, resolution, and color mode (RGB for screen, CMYK for print).

> **Resolution Guide:**
> - **72 PPI** — Screen/web use
> - **150 PPI** — Standard print
> - **300 PPI** — High-quality print (recommended for professional work)

---

### 5. Right Side Panels

The **right side** of the workspace contains a column of dockable panels that provide access to key features:

| Panel | Function |
|---|---|
| **Layers** | Manage, organize, and stack layers; apply blending modes and opacity |
| **Properties** | Context-sensitive settings for the selected layer or tool |
| **Adjustments** | Non-destructive color and tone corrections (Curves, Levels, Hue/Saturation) |
| **History** | View and revert to previous states of the document |
| **Character / Paragraph** | Typography controls for the Text Tool |
| **Color / Swatches** | Select and save colors |
| **Libraries** | Access Adobe Stock assets and saved Creative Cloud assets |

**To show or hide any panel:** Go to **Window** in the Menu Bar and click the panel name.

> **Best Practice:** Panels can be dragged, docked, collapsed, and grouped. Organize your workspace to match your workflow — save it via **Window > Workspace > New Workspace**.

## PART 2: ESSENTIAL TOOLS IN PHOTOSHOP (60 minutes)

The following tools are the most commonly used in professional Photoshop workflows. Each entry includes the shortcut key, function, and practical application.

---

### 1. Move Tool
**Shortcut: `V`**

The Move Tool is typically the first tool you use in any Photoshop session. It allows you to reposition layers, objects, and selections anywhere on the canvas.

**How to use:**
1. Press `V` or click the Move Tool icon (top of the Toolbar).
2. Click on the object or layer you want to move.
3. Drag it to the desired position.

**Additional features:**
- Enable **Auto-Select** in the Options Bar to automatically select the layer you click on.
- Hold `Shift` while dragging to constrain movement to horizontal or vertical.
- Use **arrow keys** for precise 1px nudges; hold `Shift` + arrow for 10px nudges.

---

### 2. Marquee Tools
**Shortcut: `M`**

The Marquee Tools create geometric selections on the canvas. Right-click the icon to access all variants:

| Tool | Shape | Use Case |
|---|---|---|
| **Rectangular Marquee** | Rectangle / Square | Cropping, selecting rectangular areas |
| **Elliptical Marquee** | Oval / Circle | Selecting circular areas, creating round crops |
| **Single Row Marquee** | 1px horizontal line | Selecting a single row of pixels |
| **Single Column Marquee** | 1px vertical line | Selecting a single column of pixels |

**Practical applications:** Cropping images, copying specific regions, applying effects to defined areas, creating geometric shapes for layouts.

> **Tip:** Hold `Shift` while drawing to constrain to a perfect square or circle. Hold `Alt` to draw from the center outward.

---

### 3. Lasso Tools
**Shortcut: `L`**

Lasso Tools allow freehand and semi-automatic selections for irregular shapes. Right-click to access all three:

| Tool | How It Works | Best For |
|---|---|---|
| **Lasso Tool** | Freehand — draw any shape by holding and dragging | Quick, rough selections |
| **Polygonal Lasso** | Click to place straight-edged anchor points | Selecting objects with straight edges (buildings, boxes) |
| **Magnetic Lasso** | Snaps to edges automatically based on contrast | Selecting objects with defined edges against a contrasting background |

**Practical applications:** Cutting out objects, isolating subjects, selecting complex shapes for color adjustments.

---

### 4. Crop Tool
**Shortcut: `C`**

The Crop Tool trims, straightens, and resizes the canvas. It is one of the most frequently used tools in photo editing.

**Key features:**
- Set a specific **aspect ratio** (e.g., 1:1, 16:9, 4:5) in the Options Bar.
- Enable **Content-Aware Fill** to intelligently fill cropped edges.
- **Non-destructive cropping** — by default, Photoshop hides (not deletes) cropped pixels. You can restore them by expanding the canvas later.
- Use the **Straighten** button to auto-correct tilted horizons.

> **Tip:** Press `Enter` to confirm the crop, or `Esc` to cancel.

---

### 5. Brush Tool
**Shortcut: `B`**

The Brush Tool is one of the most versatile tools in Photoshop. It simulates natural media (paint, ink, chalk) and is used for painting, sketching, retouching, and masking.

**Key settings in the Options Bar:**
- **Size** — diameter of the brush stroke
- **Hardness** — 100% = sharp edge; 0% = soft, feathered edge
- **Opacity** — how transparent the stroke is (lower = more transparent)
- **Flow** — how quickly paint builds up as you paint
- **Blend Mode** — how the brush interacts with existing pixels

**Practical applications:** Digital painting, adding texture, painting on layer masks, retouching skin, creating custom effects.

> **Tip:** Press `[` to decrease brush size and `]` to increase it. Press `Shift + [` or `Shift + ]` to adjust hardness.

---

### 6. Clone Stamp Tool
**Shortcut: `S`**

The Clone Stamp Tool copies (clones) pixels from one area of an image and paints them onto another area. It is essential for photo restoration and retouching.

**How to use:**
1. Hold `Alt` (Windows) / `Option` (Mac) and click to set the **source point**.
2. Release `Alt` and paint over the area you want to cover.

**Practical applications:** Removing blemishes, wires, watermarks, or unwanted objects; repairing damaged or torn photographs; extending backgrounds.

> **Tip:** Use a soft brush with low opacity for seamless blending. Frequently re-sample the source point to avoid repetitive patterns.

---

### 7. Eraser Tool
**Shortcut: `E`**

The Eraser Tool removes pixels from a layer. Right-click to access all three variants:

| Tool | Function |
|---|---|
| **Eraser** | Erases pixels to the background color (or transparency on unlocked layers) |
| **Background Eraser** | Samples the color under the cursor and erases matching colors — useful for removing backgrounds |
| **Magic Eraser** | Clicks to erase all similarly colored pixels at once (similar to Magic Wand + Delete) |

> **Best Practice:** Instead of erasing directly, use a **Layer Mask** for non-destructive editing. This allows you to restore erased areas at any time.

---

### 8. Gradient Tool
**Shortcut: `G`**

The Gradient Tool fills a selection or layer with a smooth transition between two or more colors.

**Gradient types:**
- **Linear** — straight line transition
- **Radial** — circular transition from center outward
- **Angle** — sweeping cone-shaped gradient
- **Reflected** — mirrored linear gradient
- **Diamond** — diamond-shaped transition

**Practical applications:** Backgrounds, sky replacements, vignettes, color overlays, smooth transitions between design elements.

> **Note:** The **Paint Bucket Tool** shares the same shortcut (`G`) and is hidden under the Gradient Tool. Right-click the Gradient Tool icon to access it. The Paint Bucket fills a selected area with a solid color or pattern.

---

### 9. Pen Tool
**Shortcut: `P`**

The Pen Tool is the most precise selection and drawing tool in Photoshop. It creates **vector paths** by placing anchor points connected by straight or curved segments.

**How to use:**
- Click to place **corner anchor points** (straight lines).
- Click and drag to place **smooth anchor points** (curves).
- Close the path by clicking the first anchor point.
- Convert the path to a selection via **right-click > Make Selection**.

**Practical applications:** Precise image cutouts (product photography, portraits), creating custom vector shapes, drawing logos and icons.

> **Tip:** The Pen Tool has a steep learning curve but produces the cleanest, most precise selections of any tool in Photoshop. It is the industry standard for professional cutouts.

---

### 10. Healing Brush Tool
**Shortcut: `J`**

The Healing Brush Tool blends sampled pixels with the texture, lighting, and shading of the surrounding area — making repairs nearly invisible.

**How to use:**
1. Right-click the **Spot Healing Brush** icon in the Toolbar and select **Healing Brush Tool**.
2. Hold `Alt` and click to set a source point.
3. Paint over the area to be repaired.

**Related tools under the same shortcut (`J`):**

| Tool | Function |
|---|---|
| **Spot Healing Brush** | Auto-samples surrounding pixels — no source point needed |
| **Healing Brush** | Manual source point — more control |
| **Patch Tool** | Select an area and drag it to a replacement region |
| **Content-Aware Move** | Move or extend objects and auto-fill the gap |
| **Red Eye Tool** | Removes red-eye from flash photography |

**Practical applications:** Skin retouching, removing blemishes, repairing scratches in old photos, removing distracting elements.

---

### 11. Text Tool (Type Tool)
**Shortcut: `T`**

The Text Tool adds and edits text within a Photoshop document. Text is created as a **vector layer**, meaning it remains sharp at any size.

**Variants:**
- **Horizontal Type Tool** — standard left-to-right text
- **Vertical Type Tool** — top-to-bottom text
- **Horizontal / Vertical Type Mask** — creates a selection in the shape of text

**Key settings:** Font family, style (Bold, Italic), size, color, alignment, anti-aliasing, tracking, leading, kerning.

**Practical applications:** Logos, posters, social media graphics, web mockups, typographic compositions.

> **Tip:** Double-click a text layer thumbnail in the Layers panel to quickly re-enter edit mode.

---

### 12. Magic Wand Tool
**Shortcut: `W`**

The Magic Wand Tool selects areas of similar color and tone with a single click. It is best suited for images with solid or clearly defined color regions.

**Key setting — Tolerance:**
- **Low tolerance (e.g., 10)** — selects only very similar colors (precise but narrow)
- **High tolerance (e.g., 50–100)** — selects a broader range of similar colors

**How to access:** Right-click the **Object Selection Tool** icon and select **Magic Wand Tool**.

**Practical applications:** Removing solid-color backgrounds, selecting sky regions, isolating flat-color shapes.

> **Tip:** Use **Select > Modify > Expand** after a Magic Wand selection to clean up jagged edges.

---

### 13. Eyedropper Tool *(commonly mislabeled — this is NOT the Magic Wand)*
**Shortcut: `I`**

> ⚠️ **Correction:** The tool with shortcut `I` is the **Eyedropper Tool**, not the Magic Wand Tool (which uses `W`). This is a common labeling error.

The Eyedropper Tool samples a color from anywhere on the canvas and sets it as the active foreground color. This ensures perfect color matching across your project.

**How to use:** Click anywhere on the canvas to sample that color. The sampled color appears in the foreground color swatch at the bottom of the Toolbar.

**Related tools under `I`:**
- **3D Material Eyedropper** — samples materials in 3D layers
- **Color Sampler Tool** — places up to 4 persistent color sample points on the canvas
- **Ruler Tool** — measures distances and angles
- **Note Tool** — adds text annotations to the document

**Practical applications:** Matching brand colors, maintaining color consistency across layers, sampling colors from reference images.

---

### 14. Dodge and Burn Tools
**Shortcut: `O`**

These two tools are used for **non-destructive tonal adjustments** directly on the image:

| Tool | Effect | Use Case |
|---|---|---|
| **Dodge Tool** | Lightens pixels | Highlighting, brightening shadows, adding shine |
| **Burn Tool** | Darkens pixels | Deepening shadows, adding depth and drama |
| **Sponge Tool** | Increases or decreases color saturation | Enhancing or muting specific areas |

**Range settings (Options Bar):**
- **Shadows** — affects only the dark areas
- **Midtones** — affects the middle tonal range
- **Highlights** — affects only the bright areas

**Practical applications:** Portrait retouching, adding depth to product photos, creating dramatic lighting effects, enhancing textures.

> **Best Practice:** Work on a **duplicate layer** or use **Dodge/Burn on a grey overlay layer** to keep edits non-destructive.

---

### 15. Patch Tool
**Shortcut: `J`** *(accessed via the Healing Brush flyout)*

> ⚠️ **Note:** The Patch Tool shares shortcut `J` with the Healing Brush group. Right-click the Healing Brush icon to access it.

The Patch Tool combines the selection capability of the Lasso Tool with the blending power of the Healing Brush. You draw a selection around a problem area, then drag it to a clean source area — Photoshop blends the replacement seamlessly.

**Modes:**
- **Normal** — standard patch replacement
- **Content-Aware** — intelligently synthesizes surrounding content for a more natural result

**Practical applications:** Removing large blemishes, skin imperfections, unwanted objects, or distracting background elements.

---

### 16. History Brush Tool
**Shortcut: `Y`**

The History Brush Tool paints back a previous state of the image from the **History Panel**, allowing selective, targeted undos without reverting the entire document.

**How to use:**
1. Open the **History Panel** (Window > History).
2. Click the checkbox next to the history state you want to restore.
3. Paint over the area you want to revert.

**Practical applications:** Restoring over-edited areas, combining multiple editing stages, selectively undoing retouching effects.

> **Tip:** The **Art History Brush** (also under `Y`) applies history states with stylized, painterly strokes — useful for creative effects.

---

### 17. Paint Bucket Tool
**Shortcut: `G`** *(accessed via the Gradient Tool flyout)*

The Paint Bucket Tool fills a selected area or a region of similar-colored pixels with a solid color or pattern.

**How to access:** Right-click the **Gradient Tool** icon in the Toolbar and select **Paint Bucket Tool**.

**Key settings:**
- **Tolerance** — controls how similar pixels must be to be filled
- **Contiguous** — when checked, only fills connected pixels; when unchecked, fills all matching pixels across the canvas
- **Fill with Pattern** — switch from foreground color to a repeating pattern fill

**Practical applications:** Filling flat-color backgrounds, coloring shapes, applying pattern fills to design elements.

## BONUS: CRITICAL CONCEPT — Photoshop is Raster-Based, Not Vector

> This is one of the most important things to understand as you grow in Photoshop. Getting this wrong leads to real, irreversible mistakes in professional work — mistakes that cannot be fixed after the fact.

---

### Raster vs. Vector: What's the Difference?

#### What is a Raster Image?

A **raster image** (also called a *bitmap*) is made up of a fixed grid of tiny colored squares called **pixels** (short for *picture elements*). Every photograph you take, every image you see on a screen — these are raster files. The quality of a raster image is determined by its **resolution**, measured in **PPI (pixels per inch)**.

- A 72 PPI image has 72 pixels packed into every inch — fine for screens.
- A 300 PPI image has 300 pixels per inch — required for sharp, professional print output.

The critical limitation: **the pixel grid is fixed at the moment of creation.** If you enlarge a raster image beyond its original resolution, Photoshop has to *invent* new pixels to fill the gaps — a process called **interpolation**. The result is a blurry, blocky, degraded image. This is called **pixelation**, and it cannot be undone once the file is saved at the lower resolution.

```
Original (100%)     Scaled to 400% (Raster)     Scaled to 400% (Vector)
┌──────────┐        ┌──────────────────────┐     ┌──────────────────────┐
│ Sharp    │  →→→   │ Blurry / Pixelated   │     │ Still perfectly      │
│ Image    │        │ ░░▒▒▓▓ degraded ▓▒░  │     │ sharp and crisp      │
└──────────┘        └──────────────────────┘     └──────────────────────┘
```

**Common raster file formats:** `.JPG`, `.PNG`, `.GIF`, `.BMP`, `.TIFF`, `.PSD`

---

#### What is a Vector Image?

A **vector image** is not made of pixels at all. Instead, it is built from **mathematical equations** that describe geometric shapes — points, lines, curves, and fills — using a coordinate system. When you scale a vector graphic, the software simply recalculates the math. The result is always perfectly sharp, at any size, on any output device.

A logo drawn as a vector can be printed on a business card at 5cm wide, or on a billboard at 10 meters wide — and it will look identical in sharpness and quality at both sizes.

**Common vector file formats:** `.AI`, `.SVG`, `.EPS`, `.PDF` (vector-based)

---

### The Direct Comparison

| Feature | Raster (Photoshop) | Vector (Illustrator / Figma) |
|---|---|---|
| **Built from** | Pixels (fixed grid) | Mathematical paths and equations |
| **Scalability** | Loses quality when enlarged | Infinitely scalable — no quality loss |
| **File size** | Larger — stores every pixel's color data | Smaller — stores only math formulas |
| **Best for** | Photos, textures, complex color blending, digital painting | Logos, icons, typography, illustrations, UI elements |
| **Resolution dependent?** | ✅ Yes — must set correct PPI before starting | ❌ No — resolution-independent |
| **Editing style** | Destructive by default (pixels are changed) | Non-destructive by nature (paths are recalculated) |
| **Output** | Screen display, photo prints, social media | Print at any scale, embroidery, signage, web icons |
| **Primary Adobe tool** | **Adobe Photoshop** | **Adobe Illustrator** |

---

### Why This Matters in Practice

This is not just theory — it has direct consequences on your work:

**Scenario 1 — The Logo Mistake:**
A student designs a company logo in Photoshop at 500×500 pixels. The client later needs it printed on a banner at 3 meters wide. When the file is scaled up, it becomes a blurry, pixelated mess. The logo has to be completely rebuilt from scratch — in a vector tool. This is an extremely common and costly mistake in professional design.

**Scenario 2 — The Resolution Trap:**
A student creates a poster in Photoshop at 72 PPI (screen resolution) instead of 300 PPI (print resolution). The poster looks fine on screen. When it goes to the printer, every edge is soft and the text looks fuzzy. The file must be recreated at the correct resolution — you cannot simply increase PPI after the fact without significant quality loss.

**Scenario 3 — The Right Tool for the Job:**
A designer needs to retouch a portrait photograph (remove blemishes, adjust skin tone, add a background). Photoshop is the correct tool — this is raster work. The same designer then needs to create the brand logo that will appear on the photo. That logo should be created in Illustrator as a vector, then *placed* into Photoshop as a Smart Object to preserve its scalability.

---

### Does Photoshop Have Any Vector Capability?

Yes — but with important limitations. Photoshop includes some vector features:

- **Shape Layers** — rectangles, ellipses, and custom shapes drawn with the Shape Tool are stored as vectors within Photoshop and remain sharp when scaled.
- **Text Layers** — all text in Photoshop is vector-based until it is *rasterized*.
- **Pen Tool Paths** — paths created with the Pen Tool are vector paths, but they are typically converted to pixel-based selections or masks.
- **Smart Objects** — vector files (like `.AI` or `.SVG`) placed into Photoshop as Smart Objects retain their vector data and can be scaled without quality loss.

> ⚠️ **However:** The moment you *rasterize* any of these elements (Layer > Rasterize), they become pixels and lose all vector scalability permanently.

**The bottom line:** Photoshop is fundamentally a raster editor. Its vector features are supplementary tools, not a replacement for a dedicated vector application. For any work that requires infinite scalability — logos, icons, brand marks, typographic layouts — use Adobe Illustrator or a vector-native tool.
